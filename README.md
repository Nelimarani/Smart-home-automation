# Smart-home-automation
🏠 Smart Home Automation System
A web-based dashboard that simulates a smart home automation system — remotely controlling appliances like lights, fans, and AC through a browser interface or simple voice-style commands. This project models the software/control layer of an IoT automation system, the same layer that would talk to a microcontroller (e.g., ESP8266/Arduino) over MQTT in a full hardware deployment.
